# Curso TMW git e github 2026

Um curso para iniciantes aprenderem a trabalhar com versionamento de codigos 
e repositorios remotos com github. 

Principais comandos, n estão em ordem.
ls -> Lista
cd -> acessar pasta no pc
git status -> saber o status do que está fazendo
git checkout -b "descrição" -> criando um Branch fora da main, onde devemos 
aplicar as edições
git add .
git commit -m "descrição para identificar a vesrão"
touch nome_que_arquivo -> criando um novo arquivo na pasta que está trabalhando
git push origin main -> comando para conectar o branch do git com github
